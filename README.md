# Карта путешествий

Интерактивная карта мира: отмечайте страны, где уже побывали и куда хотите поехать.
Проект создан с помощью инструментов искусственного интеллекта.

## Файлы

| Файл | Зачем нужен |
|---|---|
| `index.html` | Весь сайт: карта, стили и код в одном файле |
| `manifest.webmanifest` | Описание приложения для установки на телефон |
| `sw.js` | Кэш, благодаря которому карта открывается без интернета |
| `icon-192.png`, `icon-512.png` | Иконки приложения |

## Как открыть

Дважды щёлкните по `index.html` — сайт откроется в браузере.
Установка как приложения и работа без интернета включаются только после публикации в интернете.

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на github.com.
2. Загрузите в него все файлы из этой папки.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Через пару минут сайт будет доступен по адресу `https://ваш-логин.github.io/название-репозитория/`.

## Что умеет

- Отметка стран: был, хочу побывать, снять отметку
- Карточка страны: флаг, столица, население, площадь и краткое описание из Википедии
- Даты поездок и личные заметки по каждой стране
- Статистика: доля стран, населения мира и площади суши
- Разбивка по частям света
- Маршрут между странами с расчётом расстояния
- Случайный выбор направления из списка желаний
- Сохранение отметок в файл и загрузка обратно
- Скачивание карты картинкой

## Источники данных

- Контуры стран: пакет `pygal_maps_world` (открытая лицензия)
- Названия стран: библиотека `babel` (Unicode CLDR)
- Столицы, население, площадь, координаты: набор данных `countryinfo`
- Краткие описания: API Википедии
- Флаги: flagcdn.com
